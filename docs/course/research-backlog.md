# Research Backlog

This file tracks what must be verified before Teaching Practice Lab turns a topic into published course material.

The rule is simple:

> If the source is incomplete, the course should say so. Do not fill framework gaps from memory.

## Priority 0 — Required before full FTEM authoring

### Standards-Based Planning exact labels

Current public Marzano Evaluation Center material clearly identifies a three-competency Planning domain and explicitly names **Planning Standards-Based Lessons/Units**, while describing the other planning areas.

Need:

- exact current canonical names of all three planning competencies,
- current desired-effect wording or sufficiently authoritative descriptions for internal analysis,
- current public evidence/technique descriptions that can be safely paraphrased,
- confirmation of any recent terminology changes.

Preferred source:

1. current official FTEM protocol/report,
2. current licensed district/state copy if legally available,
3. direct Marzano Evaluation Center material.

Do not encode guessed labels.

### Current model version history

Need a clean timeline documenting:

- 2011 Art and Science / 60-element Learning Map,
- development/release of the Focused Teacher Evaluation Model,
- significant public revisions or updates,
- whether any newer teacher model has formally superseded FTEM.

This timeline should distinguish **model release**, **document update**, and **website update**.

## Priority 4 — Observation and defense research

Need authoritative current material on:

- observation process,
- desired-effect monitoring,
- adaptation,
- student evidence,
- post-observation conversation,
- observer calibration/inter-rater reliability,
- teacher self-assessment.

Boundary:

Teaching Practice Lab can train reasoning from publicly documented concepts, but must not claim to provide official observer certification or reproduce licensed scoring protocols.

## Priority 5 — Learning science

Current foundation:

- retrieval practice,
- transfer through testing,
- distributed practice.

Potential additions to research carefully:

- self-explanation,
- worked examples and fading,
- interleaving/discrimination learning,
- feedback timing,
- desirable difficulties,
- generation effect.

Only add these when a primary or high-quality research source has been reviewed and the design implication is clear.

## Priority 6 — New Jersey implementation context

Research separately from FTEM itself:

- current NJDOE approved teacher-practice instrument rules,
- district flexibility,
- Middle Township's actual chosen instrument/version if a public source is available,
- district observation procedures if public,
- distinction between state requirements, district implementation, and Marzano model guidance.

Do not present district-specific claims until verified.

## Source note template

For every significant research addition, record:

```text
Claim:
Source:
Publisher:
Publication/update date:
Access date:
Primary or secondary:
What the source supports:
What it does NOT support:
Copyright/redistribution notes:
Course pages affected:
Open questions:
```

This makes later agent authoring much safer because the source boundary is explicit before content generation begins.
