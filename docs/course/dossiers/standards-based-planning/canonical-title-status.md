# Standards-Based Planning Canonical Title Status

This note exists to prevent a subtle source-integrity error: treating older or secondary labels as if they were verified current FTEM titles.

## Confirmed by current MEC public material

Current MEC public material confirms:

- Domain: **Standards-Based Planning**
- Number of elements: **3**
- Element 1: **Planning Standards-Based Lessons/Units**
- Element 2 function: connect aligned tasks to traditional/digital resources that match the standard and appropriate taxonomy level
- Element 3 function: plan measures that track all students' progress and help close achievement gaps

The current FTEM overview also summarizes the domain as:

- planning standards-based lessons,
- aligning resources,
- using data to close gaps.

## Working/historical labels

Older Focused Teacher Evaluation materials and secondary references commonly use:

- **Aligning Resources to Standard(s)**
- **Planning to Close the Achievement Gap Using Data**

These labels are highly plausible and consistent with the current public functional descriptions, but Teaching Practice Lab will not mark them as current canonical titles until one of the following confirms them:

1. current official MEC protocol,
2. current official FTEM report containing the element names,
3. current MEC-published electronic protocol access,
4. another current first-party MEC document that explicitly lists the titles.

## Why this matters

The course can teach the planning mechanisms now without pretending uncertain labels are settled.

This is preferable to silently copying a 2017 label into a 2026 course and presenting it as current.

## Publication rule

Until resolved:

- internal research files may mention the historical/working labels with a status note,
- public lesson titles should either use the confirmed functional phrasing or visibly note that the exact current title is unresolved,
- no exact focus statement, desired effect, protocol evidence, or developmental-scale language should be invented.

## Current conclusion

**Planning research baseline: usable. Exact canonical title verification for Elements 2 and 3: still open.**
