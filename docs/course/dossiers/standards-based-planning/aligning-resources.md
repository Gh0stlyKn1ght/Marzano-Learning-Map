# Standards-Based Planning Element 2: Aligning Resources

## Status

**Function confirmed by current MEC public material. Exact current canonical title not yet confirmed.**

Current MEC material says Element 2 guides teachers to connect aligned tasks to traditional and digital resources that match the standard and the appropriate taxonomy level. Older Focused Teacher Evaluation materials commonly use the title **Aligning Resources to Standard(s)**. Teaching Practice Lab treats that wording as a working/historical label until a current authoritative protocol/report confirms it.

## Verified public-source claims

Current MEC material supports these points:

- resources should support standards-aligned tasks,
- resource selection should match the intended cognitive level,
- both traditional and digital resources may be relevant,
- resource choice is part of planning rather than an afterthought.

## Teaching Practice Lab interpretation

A resource is not "good" merely because it is current, interactive, expensive, popular, or technological. It is useful when it helps students perform the kind of thinking the standard and task require.

The planning question is:

> What resource gives students the right information, representation, tool, or environment to do the intended cognitive work?

## Original examples

### Computer systems

If students must compare CPU scheduling policies, a static definition sheet may support vocabulary, but a simulator or trace table may better support analysis of tradeoffs.

### Cybersecurity

If students must explain network evidence, a packet capture can be a strong resource because it exposes authentic structure. A polished video may be useful for orientation but insufficient for the analysis task itself.

### Programming

If students must debug a program, a runnable code example with observable output may be better aligned than a slide deck explaining syntax.

### Esports

If students must analyze team decision-making, match footage with timestamps and a structured analysis guide may align better than a general article about strategy.

## False positives

These do not establish resource alignment:

- using technology because it is available,
- assigning a video because it covers the topic,
- giving students many links,
- using an advanced tool that adds cognitive noise,
- choosing a resource only because students enjoy it,
- selecting a resource that addresses the topic but not the target's cognitive demand.

## Nearest concepts

### Aligning Resources vs Planning Standards-Based Lessons/Units

Lesson/unit planning defines the target, task, and cognitive demand. Resource alignment asks whether the materials/tools selected actually support that design.

### Aligning Resources vs Engagement Strategies

A resource may be engaging, but engagement is not the same as alignment. A flashy simulation can still be poorly aligned to the intended learning.

### Aligning Resources vs Universal Design / accessibility

Accessibility and learner access are important design considerations, but Teaching Practice Lab should not automatically present all accessibility decisions as official FTEM resource-alignment requirements unless current MEC source material supports that specific claim.

## Adaptation questions

- Does this resource help students perform the intended task or merely consume information?
- Is the reading/interface/tool complexity appropriate for the target?
- Does the resource lower the cognitive demand by doing the thinking for students?
- Is the resource more complex than the learning problem requires?
- What alternative representation or tool would preserve rigor while improving access?

## Defense prompts

- Why did you choose this resource rather than another one?
- How does the resource support the standard and cognitive demand?
- What would students be unable to do if this resource were removed?
- Does the tool support thinking or replace thinking?
- How do you know the resource is helping rather than distracting?
