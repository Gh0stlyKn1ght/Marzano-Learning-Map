# Standards-Based Planning Research Dossiers

These dossiers prepare the source-grounded knowledge needed to author the Standards-Based Planning course. They are research records, not official Marzano protocols.

## Current source status

Current Marzano Evaluation Center material confirms that Standards-Based Planning contains **3 elements**. The current public article explicitly names **Planning Standards-Based Lessons/Units** and describes Elements 2 and 3 functionally:

- Element 2 connects aligned tasks to traditional and digital resources that match the standard and the appropriate taxonomy level.
- Element 3 ensures planning includes measures that track all students' progress and support closing achievement gaps.

The current FTEM overview summarizes the domain as planning standards-based lessons, aligning resources, and using data to close gaps.

Older Focused Teacher Evaluation materials and secondary references commonly label Elements 2 and 3 as **Aligning Resources to Standard(s)** and **Planning to Close the Achievement Gap Using Data**. Teaching Practice Lab will treat those as **working/historical labels until a current authoritative MEC protocol/report confirms the exact canonical wording**.

## Shared planning logic

```text
standard / target
      ↓
cognitive demand
      ↓
task design
      ↓
resources aligned to task + standard
      ↓
measures of student progress
      ↓
planned responses to evidence / gaps
```

The core idea is alignment before instruction begins. A strong plan should not merely contain activities. It should connect standards, intended cognitive demand, student tasks, resources, evidence, and planned responses.
