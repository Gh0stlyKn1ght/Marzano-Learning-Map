# Conditions for Learning Research Dossiers

These dossiers prepare the source-grounded knowledge needed to author the **Conditions for Learning** course. They are research records, not official Marzano protocols.

## Verified current structure

Current Marzano Evaluation Center material identifies seven elements in this domain and groups them around three themes:

1. **Monitoring Student Progress and Feedback**
   - Using Formative Assessment to Track Progress
   - Providing Feedback and Celebrating Progress
2. **Rigorous Learning**
   - Organizing Students to Interact with Content
   - Using Engagement Strategies
3. **Classroom Environment**
   - Establishing and Acknowledging Adherence to Rules and Procedures
   - Establishing and Maintaining Effective Relationships in Student-Centered Classrooms
   - Communicating High Expectations for Each Student to Close the Achievement Gap

Primary source IDs: `MEC-ELEMENTS`, `MEC-CLASSROOM-CONDITIONS`, `MEC-FTEM-CURRENT`.

## Dossier rule

Each file separates:

- **Verified public-source claims**
- **Teaching Practice Lab interpretation**
- **Original classroom examples / non-examples**
- **Defense questions**
- **Unresolved protocol-level details**

Do not promote our interpretation into official Marzano wording.

## Shared reasoning test

For every element, the learner should eventually be able to answer:

- What classroom condition is this element trying to create?
- What student behavior or evidence would indicate the condition exists?
- What visible behavior could create a false positive?
- How is this element different from its closest neighbor?
- What should the teacher change if the condition is not present?
- How would the teacher defend the decision to an administrator or coach?
