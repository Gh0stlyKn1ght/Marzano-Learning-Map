# Roadmap

## Phase 1: Documentation foundation

- Canonical GitHub navigation
- MkDocs Material site
- Source registry and copyright policy
- FTEM framework/version notes
- Agent instructions and research skills
- Mermaid diagram conventions

## Phase 2: Training knowledge base

- One original learning page per current competency
- Mechanism, evidence, failure modes, adaptation, and classroom scenarios
- Deliberate-practice exercises
- Calibration scenarios
- Framework history and carefully sourced crosswalk notes

## Phase 3: Structured data

- Stable IDs for domains and competencies
- Practice/evidence JSON schemas
- Zod-compatible schema design
- Content validation scripts
- Source/provenance metadata

## Phase 4: Personal practice tool

- Local-first practice journal
- Observation prep workflow
- Reflection workflow
- Evidence timeline
- Growth targets

## Phase 5: Reporting

- Observation brief
- Lesson evidence report
- Practice growth report
- Domain evidence portfolio
- Professional growth report
- Print-first CSS/PDF export

## Phase 6: Interactive knowledge map

- Next.js application
- React Flow domain/competency/evidence graph
- Drill-down from practice to evidence and reports
- Search and filters

## Phase 7: Reflection intelligence

Only after the evidence model is trustworthy:

- missing-evidence prompts,
- reflective questioning,
- synthesis of user-supplied records,
- trend detection,
- no automated official evaluation claims.
