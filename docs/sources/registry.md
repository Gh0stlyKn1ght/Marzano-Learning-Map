## Rules

- Add a source here before treating it as a foundational reference.
- Prefer the canonical publisher URL over mirrors.
- Do not upload/republish restricted source content merely to make it easier for agents to access.
- When a source changes substantially, preserve the access date and add a source note or snapshot metadata if legally permissible.
- A source registry entry does **not** imply redistribution rights.
