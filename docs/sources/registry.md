# Source Registry

This is the human-readable source registry for Teaching Practice Lab. It records the sources that are allowed to drive framework claims, course design decisions, and technical architecture.

A source appearing here does **not** mean its text, graphics, protocols, scales, or training materials may be republished. The registry records provenance, not redistribution rights.

## Source hierarchy

When sources disagree or when details are incomplete, use this order:

1. current official Marzano Evaluation Center model/protocol material,
2. current official Marzano Evaluation Center articles or reports,
3. licensed district/state implementation materials when legally available,
4. peer-reviewed research for learning-science claims,
5. historical Marzano material for lineage/context,
6. secondary commentary only for discovery or comparison.

Historical material must never silently override the current FTEM model.

## Rules

- Add a source here before treating it as a foundational reference.
- Prefer the canonical publisher URL over mirrors.
- Distinguish **framework claims** from **our instructional design decisions**.
- Do not invent exact element labels when an authoritative current source has not confirmed them.
- Do not upload or republish restricted source content merely to make it easier for agents to access.
- When a source changes substantially, preserve the access date and add a source note or legally permissible snapshot metadata.
- A source registry entry does **not** imply redistribution rights.
- Course examples, scenarios, diagrams, comparisons, and explanations should be original unless a source is explicitly quoted within copyright limits.
