# Source Policy

This repository is research-driven. Framework claims must be traceable.

## Source hierarchy

Use sources in this order whenever possible:

1. **Official/current framework sources** from the Marzano Evaluation Center or relevant rights holder.
2. **Government/district sources** when documenting local evaluation policy or implementation requirements.
3. **Peer-reviewed research** for empirical claims.
4. **Books and scholarly publications** for historical or conceptual background.
5. **Secondary commentary** only for discovery, interpretation, or comparison.

Do not allow a blog summary to override an official protocol or current model description.

## Claim classes

Every substantial research note should distinguish among:

- **Source fact** — directly supported by a cited source.
- **Paraphrase** — our restatement of a supported idea.
- **Interpretation** — our analysis of what the material means.
- **Design decision** — a product choice made by this repository.
- **Classroom example** — an original example, not a statement from Marzano.

## Citation rule

Prefer stable canonical links. Record access date for web sources that may change. For downloaded documents, record title, publisher/author, publication date when known, original URL, and local-use restriction.

## Proprietary-material boundary

A source being publicly downloadable does not make it freely reusable. Do not commit full proprietary rubrics, protocols, training decks, PDFs, scoring guides, or branded graphics unless the license or written permission allows redistribution.

The historical 2011 Learning Map supplied to this project explicitly states a digitization restriction. It may be used as a research reference, but this repository should not reproduce it as a public digital clone.

## Evidence standard

If a framework page makes a claim such as "the current model has 23 competencies," the page must cite the official current source. If we infer a crosswalk between an older and newer framework, label the crosswalk as our analysis unless an authoritative source provides the mapping.
