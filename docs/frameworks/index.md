# Frameworks

The repository distinguishes current and historical models instead of flattening them together.

## Current research target

[Marzano Focused Teacher Evaluation Model](ftem/index.md)

Current official Marzano Evaluation Center materials describe FTEM as 23 competencies across four domains.

## Historical reference

[2011 Teacher Evaluation Model](legacy-2011/index.md)

The user-supplied 2011 Learning Map contains the older 60-element model. It is retained as historical research context, not as the default training target.

## Version rule

See [Framework Versioning](versioning.md). Every canonical framework claim must make clear which version it refers to.
