# Source Research Skill

## Purpose

Use this skill when adding, verifying, or updating claims about teaching frameworks, evaluation systems, research, law/policy, standards, or technical dependencies.

## Workflow

1. State the exact claim or question being researched.
2. Search for a primary/current source first.
3. Record whether the source is official, governmental, peer-reviewed, scholarly, or secondary.
4. Capture publication/update date when available and access date for web sources.
5. Extract only the information needed to support the claim.
6. Do not silently reconcile conflicting versions. Record the conflict.
7. Add foundational sources to `docs/sources/registry.md`.
8. Write analysis in our own words and link to the source.
9. If a source appears proprietary or redistribution-restricted, cite it without cloning it.

## Required labels in research notes

Use these labels when ambiguity exists:

- `Source fact:` directly supported.
- `Interpretation:` our analysis.
- `Open question:` not yet resolved.
- `Design implication:` what the source means for the product.

## Failure conditions

Stop and mark unresolved if:

- the source version cannot be established,
- a secondary source conflicts with the official source,
- a claim depends on inaccessible proprietary language,
- exact terminology is uncertain,
- a local district implementation is being inferred from the national framework.

Never fill those gaps from model memory.
